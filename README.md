## What is this?

Alive Readme turns plain README links into real, good-looking buttons. You choose the text, colours, icon and animation on a web page, and it hands you a ready-made snippet that points the button wherever **you** want.

Every button above is generated by this project, and each one is just an image from a URL.

## Use it in 3 steps

1. Open the **[button maker](https://spooky8823.github.io/Alive-Readme/)** and pick a preset or design your own.
2. Type the text and the link you want it to open, then click **Copy Markdown**.
3. Paste it into your README (or any page that shows Markdown or HTML).

The snippet looks like this:

```md
[![Download](https://alive-readme-buttons.spookyminecraftgamer.workers.dev/btn.svg?text=Download&icon=download&fill=gradient&style=pill&anim=shine)](https://your-link-here.com)
```

The first part (inside `![ ]( )`) is the button image. The part in the last brackets is where a click goes, and that's why every button can point to a different place.

## Button options

Add these after `/btn.svg?` and join them with `&`. Colours are hex values **without** the `#`.

| Option   | What it does                              | Values                                                                 | Default            |
|----------|-------------------------------------------|------------------------------------------------------------------------|--------------------|
| `text`   | Button label (up to 40 characters)        | any text, use `+` for spaces                                           | `Button`           |
| `icon`   | Icon to the left of the text              | see the icon list below                                                | none               |
| `bg`     | Background colour                         | e.g. `6c63ff`                                                          | `6c63ff`           |
| `fg`     | Text and icon colour                      | e.g. `ffffff`                                                          | white (outline: `bg`) |
| `fill`   | Background style                          | `solid`, `gradient`, `outline`                                         | `solid`            |
| `style`  | Corner shape                              | `flat`, `rounded`, `pill`                                              | `flat`             |
| `size`   | Button size                               | `sm`, `md`, `lg`                                                       | `md`               |
| `border` | Border colour                             | e.g. `ffffff`                                                          | none               |
| `anim`   | Animation                                 | `shine`, `pulse`                                                       | none               |
| `ipath`  | Your own icon                             | an SVG path on a 24×24 grid, filled, up to 3000 characters             | none               |

### Icons

`download` `windows` `terminal` `github` `external` `star` `book` `mail` `link` `globe` `code` `heart` `play` `x` `youtube` `spotify` `discord` `google`

Need a different one? Use `ipath` with a path from [simpleicons.org](https://simpleicons.org), or add it to [`buttons/src/brand-icons.js`](buttons/src/brand-icons.js).

## Run your own copy

The button images are served by a small Cloudflare Worker, so you can host your own on a free account.

1. Fork this repo.
2. In the Cloudflare dashboard, go to **Workers & Pages**, then **Create**, then import your fork. Set the **root directory** to `buttons` and leave the build command empty.
3. After it deploys, turn on the `workers.dev` address under the Worker's **Domains** tab.
4. In `index.html`, change `API_BASE` to your Worker's address and turn on GitHub Pages for the repo.

Or from a terminal:

```bash
cd buttons
npm install
npx wrangler login
npm run deploy
```

## How it works

```
Alive-Readme
├── index.html              the button maker page (GitHub Pages)
└── buttons
    ├── src
    │   ├── button-svg.js   draws the button as an SVG
    │   ├── brand-icons.js  brand logo paths
    │   └── index.js        Worker entry: serves /btn.svg
    ├── package.json
    └── wrangler.toml
```

`button-svg.js` is shared: the Worker uses it to serve images, and the maker page uses it to show your live preview.
