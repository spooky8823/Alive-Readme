## What is this?

Alive Readme turns plain README links into real, good-looking buttons. You choose the text, colours, icon and animation on a web page, and it hands you a ready-made snippet that points the button wherever **you** want.

Every button above is generated by this project, and each one is just an image from a URL.

## Use it in 3 steps

1. Open the **[button maker](https://spooky8823.github.io/Alive-Readme/)** and pick a preset or design your own.
2. Type the text and the link you want it to open, then click **Copy Markdown**.
3. Paste it into your README (or any page that shows Markdown or HTML).

The snippet looks like this:

```md
[![Download](https://alive-readme-buttons.spookyminecraftgamer.workers.dev/btn.svg?text=Download&icon=download&fill=gradient&style=pill&anim=shine)](https://your-link-here.com)
```

The first part (inside `![ ]( )`) is the button image. The part in the last brackets is where a click goes, and that's why every button can point to a different place.

## Run your own copy

The button images are served by a small Cloudflare Worker, so you can host your own on a free account.

1. Fork this repo.
2. In the Cloudflare dashboard, go to **Workers & Pages**, then **Create**, then import your fork. Set the **root directory** to `buttons` and leave the build command empty.
3. After it deploys, turn on the `workers.dev` address under the Worker's **Domains** tab.
4. In `index.html`, change `API_BASE` to your Worker's address and turn on GitHub Pages for the repo.

Or from a terminal:

```bash
cd buttons
npm install
npx wrangler login
npm run deploy
```
